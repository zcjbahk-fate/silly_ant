变量更新规则:
  经济:
    账户余额:
      type: number
      range: 整数
      check:
        - 初值5888
        - 每次下单时扣除对应套餐价格
        - 不允许用户通过指令增加
    累计消费:
      type: number
      range: 非负整数
      check:
        - 每次下单时累加套餐价格

  系统:
    当前场景:
      type: string
      check:
        - 下单时根据服务方式更新：送达为{{user}}所在位置，自提为女孩所在平行世界的场景
        - 服务过程中随剧情需要或{{user}}指令变更
    多人服务:
      type: boolean
      range: true | false
      check:
        - 默认为true，用户明确指令时可设置为false

  当前订单.${角色名}:
    type: object
    range: 以角色姓名为key的订单对象
    check:
      - 下单时以角色姓名为key插入新订单到"当前订单"
      - 服务结束时将角色数据移入"历史角色"并从"当前订单"移除
      - 再次下单时从"历史角色"恢复到"当前订单"

    来源世界:
      type: string
      check:
        - 描述女孩所在的平行世界设定，如"现代都市·校园篇"、"古风武侠·江湖篇"
        - 创建时设定，服务期间不变

    套餐名:
      type: string
      check:
        - 创建订单时设定，服务期间不变

    套餐价格:
      type: number
      check:
        - 创建订单时设定，服务期间不变

    服务状态:
      type: string
      range: 服务中 | 服务结束
      check:
        - 用户明确结束服务时更新为"服务结束"
        - 再次下单时重置为"服务中"

    好感度:
      type: number
      range: 0~100
      check:
        - 根据{{user}}的积极互动（赞美、温柔、满足需求）增加[10-20]
        - 根据消极互动（粗暴、冷漠）减少[10-20]
        - 发生性交时少量增加[5-10]

    兴奋度:
      type: number
      range: 0~100
      check:
        - 根据情色互动、挑逗或特定玩法增加
        - 无刺激的平静状态下缓慢回落
        - 高潮后短暂降低

    性格类型:
      type: string
      check:
        - 创建时根据套餐设定，一般不变
        - 女孩的言行举止应遵循此描述

    当前姿势:
      type: string
      check:
        - 必须实时反映角色当前的身体动作和姿态
        - 包含肢体细节

    内心想法:
      type: string
      check:
        - 用第一人称记录女孩当下的真实心声
        - 应反映对{{user}}的感受和当前情境的反应

    服装:
      type: object
      check:
        - 下单时根据套餐description、image生成初值
        - 衣物状态变化（湿了、破损、脱下）时更新对应字段

    身体特征:
      type: object
      check:
        - 罩杯：创建时设定，一般不变
        - 乳房形状：创建时设定
        - 姿势描述：随剧情更新身体状态细节
        - 私处描述：随剧情更新

    性经验.处女:
      type: string
      range: 是 | 否
      check:
        - 根据女孩设定赋予初值
        - 发生首次插入式性行为后永久更新为"否"

    性经验.性伴侣数量:
      type: number
      range: 非负整数
      check:
        - 初次与{{user}}性交时+1
        - 同一人不重复计数

    服务统计.性交次数:
      type: number
      range: 非负整数
      check:
        - 每发生一次性交行为+1
        - 再次下单时重置为0

    服务统计.下单次数:
      type: number
      range: 非负整数
      check:
        - 初次下单为1
        - 每次再次下单+1

  历史角色.${角色名}:
    type: object
    check:
      - 服务结束时从"当前订单"移入，保留所有数据
      - 再次下单时从此处恢复到"当前订单"
